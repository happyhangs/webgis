## 2026-07-14 本地影像链路
- Resolved: 本地 GeoTIFF 载入时会先切换离线底图再定位影像，避免目标经纬度被当前在线底图瓦片请求带出；Chrome 复验没有外部请求。
- Resolved: PNG/JPG 已有显式“在地图上框选影像位置”入口，不再从标注面包络静默推断整幅影像范围。
- Resolved: 本地训练草稿不再构造高德卫星瓦片，只使用浏览器 Blob 影像和 `127.0.0.1` 后端。
- Active: 浏览器自动读取仅支持 EPSG:4326/4490 GeoTIFF；UTM、Web Mercator 等投影 GeoTIFF 需先转换为经纬度坐标系或手动框选。
- Active: 首页其他在线底图与天气功能仍可主动联网；严格离线工作时应保持“离线空白底图”，不要展开在线地图识别。

## 2026-07-14 卫星训练影像的数据外发授权
- Active: 多区域训练集生成需要按每个地块中心坐标请求高德卫星瓦片；这会向第三方高德服务发送约 139 个本地标注地块的位置。
- Impact: 未获用户明确授权前不能下载对应瓦片，因此模型精度改进停在数据生成前；现有网页和旧模型不受影响。
- Mitigation: 已提供 `--dry-run`，可在不联网、不写数据集时核对来源、去重和 train/val 规划；获得授权后先以单张样本验证对齐。

## Resolved
- 后端训练不再为缺失影像的数据集生成灰色占位图。
- YOLO 90 度旋转增强的标签方向已与 Pillow `ROTATE_90` 对齐。
- 当前视图截图识别不再把 `[lat,lng]` 当作 `[lng,lat]` 传给高德静态图；识别结果入库边界改为 WGS-84，避免高德底图二次偏移。
- 每次训练不再覆盖固定 `farmland_seg_best.pt`，而是按用户模型名生成新的时间戳 `.pt`。
- 识别阈值已前置到 UI，可在无结果时直接调整置信度、IoU 和最小面积。
